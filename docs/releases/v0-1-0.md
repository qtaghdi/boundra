# Boundra v0.1.0

## Release Summary

`boundra@0.1.0` was accidentally published from the workspace root as a repository snapshot. It does not include the supported runtime exports or CLI entry point and should not be used as a normal Boundra release.

## Highlights

- This is not an official feature release.
- The package name was reserved on npm, but the published package did not include a usable public runtime or CLI surface.

## Installation

Do not install this version. If it is already installed, upgrade to the first supported public preview:

```bash
pnpm add boundra@^0.1.1 zod
```

## Breaking Changes

- `0.1.0` is excluded from the supported release line.
- Upgrade to `0.1.1` or later to use the supported package exports.

## Known Limitations

- No `exports` field is provided.
- No `bin` entry is provided.
- Workspace source, CI configuration, documentation, and internal repository files are included in the tarball.

## Verification

- Inspected the public npm tarball and confirmed that it contained 105 repository files.
- Confirmed that no supported runtime import path or CLI execution path was available.
