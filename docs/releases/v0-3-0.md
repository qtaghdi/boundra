# Boundra v0.3.0

## Release Summary

Boundra v0.3.0은 개발 중 발생한 contract validation과 domain boundary 문제를
한 화면에서 추적할 수 있도록 Vite 개발 에러 뷰를 확장한 릴리스입니다. 첫 번째
오류만 표시하던 제한을 제거하고, 안전하게 정규화된 진단 정보를 탐색·복사하여
애플리케이션 디버깅과 이슈 보고에 바로 사용할 수 있습니다.

## Highlights

- 모든 runtime validation issue와 boundary violation을 목록으로 표시합니다.
- Runtime과 Boundaries 탭을 제공하며 두 진단 소스의 상태를 독립적으로
  유지합니다.
- contract, validation phase, issue code, field path, file, line, import를
  상세 화면에서 확인할 수 있습니다.
- 정규화된 안전 필드만 포함하는 텍스트 보고서를 클립보드에 복사할 수 있습니다.
- boundary 진단에서 Vite의 개발 서버를 통해 해당 파일을 에디터로 열 수 있습니다.
- `Escape` 종료, 키보드 focus, 모바일 레이아웃과 reduced-motion 설정을
  지원합니다.

## Installation

Node.js 20 이상에서 설치하거나 업데이트합니다.

```bash
pnpm add boundra@0.3.0 zod
pnpm exec boundra check-boundaries
```

Vite 애플리케이션에서 개발 에러 뷰를 활성화합니다.

```ts
import { boundra } from "boundra/vite";

export default {
  plugins: [boundra()],
};
```

native archive 또는 Rust source 설치도 지원합니다.

```bash
cargo install --git https://github.com/qtaghdi/boundra --tag v0.3.0 boundra-cli
```

## Breaking Changes

없음. 기존 runtime error JSON, Vite plugin 설정, boundary JSON 출력과 CLI
인터페이스는 그대로 유지됩니다.

## Known Limitations

- 개발 에러 뷰는 현재 Vite 개발 서버 전용이며 Next.js adapter는 제공하지
  않습니다.
- 자동으로 수명주기를 판단할 수 없는 runtime 오류는 사용자가 닫기 버튼이나
  `Escape`로 제거해야 합니다. boundary 진단은 clean re-check에서 자동으로
  제거됩니다.
- 에러 뷰는 unhandled `BoundraRuntimeError`를 포착합니다. 애플리케이션에서
  처리한 오류는 애플리케이션이 직접 표시해야 합니다.
- 에디터 이동은 Vite 개발 서버와 로컬 editor integration이 필요합니다.
- 원본 contract input/result, schema provider 오류 객체와 cause는 개인정보 및
  비밀정보 보호를 위해 표시하거나 복사하지 않습니다.
