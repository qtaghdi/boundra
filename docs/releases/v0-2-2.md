# Boundra v0.2.2

## Release Summary

Boundra v0.2.2는 실제 단일 앱 저장소 dogfooding에서 확인된 경계 검사,
code generation, HTTP 오류 처리의 통합 문제를 해결한 패치 릴리스입니다.
생성된 계약이 기본 경계 규칙과 충돌하지 않으며, 검사 범위와 transport 오류를
애플리케이션에서 더 안전하고 구조적으로 다룰 수 있습니다.

## Highlights

- `paths.apps`가 `.`이어도 generated shared contract의 `boundra`와 schema
  provider import가 BR-003으로 잘못 보고되지 않습니다.
- `check-boundaries --format json`이 `scanned_file_count`와
  `analyzed_domain_count`를 제공합니다.
- source file 또는 분석된 도메인이 0개이면 text 출력에 경고가 표시됩니다.
- query, mutation, resource generator가 client adapter를 `client/public.ts`에
  idempotent하게 export합니다.
- public API 갱신 실패 시 생성 파일, manifest, barrel 변경을 원상복구합니다.
- non-2xx 응답은 status, 안전한 header allowlist, 제한된 body를 포함하는
  `BoundraHttpError`로 보존됩니다.

## Installation

Node.js 20 이상에서 설치하거나 업데이트합니다.

```bash
pnpm add boundra@0.2.2 zod
pnpm exec boundra check-boundaries
```

native archive 또는 Rust source 설치도 지원합니다.

```bash
cargo install --git https://github.com/qtaghdi/boundra --tag v0.2.2 boundra-cli
```

## Breaking Changes

없음. 기존 contract, transport, generator 명령과 boundary JSON 필드는 그대로
유지되며 coverage metadata와 structured HTTP error 정보만 추가됩니다.

## Known Limitations

- `analyzed_domain_count`는 설정된 scan에 포함된 source file이 있는 도메인을
  계산하며, 런타임 사용량이나 graph 연결 수를 의미하지 않습니다.
- HTTP 오류 body는 기본 64 KiB까지만 보존되고 초과분은 잘립니다.
- `BoundraHttpError.headers`는 `content-type`, `retry-after`, `etag`,
  `x-request-id`, `x-correlation-id`만 제공합니다.
- npm CLI 최초 실행은 cache가 없으면 GitHub Release 접근과 Unix `tar` 또는
  Windows PowerShell이 필요합니다.

## Verification

- Rust workspace 전체 테스트와 Clippy `-D warnings`
- BR-003 root-app regression 및 실제 domain scan coverage 테스트
- generator client barrel idempotency, rollback, retry 테스트
- TypeScript typecheck와 structured HTTP error runtime 테스트
- Vite integration 및 example boundary 검사
- packed npm runtime과 native CLI clean-room verification
- Linux x64, macOS x64/arm64, Windows x64 release workflow
